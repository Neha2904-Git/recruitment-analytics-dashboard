# Recruitment Analytics Dashboard 📊

A practical recruitment analytics framework for tracking hiring performance, sourcing effectiveness, and recruitment pipeline activity.

## 🎯 Objectives

Recruitment analytics can help Talent Acquisition teams:

- Monitor hiring progress
- Identify effective sourcing channels
- Track recruitment efficiency
- Understand candidate conversion
- Improve hiring decisions
- Identify bottlenecks in the recruitment process

## 📈 Key Recruitment Metrics

| Metric | What It Measures |
|---|---|
| Time to Hire | Time taken from candidate identification to hiring |
| Time to Fill | Time taken to fill an open position |
| Offer Acceptance Rate | Percentage of offers accepted by candidates |
| Source Effectiveness | Performance of different candidate sourcing channels |
| Screening-to-Interview Rate | Percentage of screened candidates progressing to interview |
| Interview-to-Offer Rate | Percentage of interviewed candidates receiving offers |
| Offer-to-Join Rate | Percentage of offered candidates who eventually join |

## 🔎 Sourcing Channel Analysis

Common sourcing channels include:

- Naukri
- LinkedIn
- Indeed
- Employee Referrals
- Internal Talent Database
- Professional Networks

### Example Analysis

A recruitment team can compare sourcing channels based on:

**Candidates Sourced → Candidates Screened → Interviews → Offers → Joins**

This helps identify which channels produce the highest-quality candidates.
